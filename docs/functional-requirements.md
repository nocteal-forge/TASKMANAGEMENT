| ID | 機能 | 内容 | ラベル |
| --- | --- | --- | --- |
| F-01 | 4 分類の表示 | 「今日」「明日」「今週」「完了」の 4 つに分けてタスクを表示する | 確定 |
| F-02 | ドラッグ&ドロップ | タスクを分類間で移動できる(PC。スマホは長押しメニュー) | 確定 |
| F-03 | データ保存 | API 経由でデータベースに保存し、ブラウザを閉じても残る | 確定 |
| F-04 | タスクの追加・編集・削除 | ・各分類の列に「タスクを追加」ボタンを置く(PC。スマホは screen-design.md「操作方法の整理」の入力開始エリア)。追加した列の分類が初期分類になる<br>・PC では、ボタンを押すと列の末尾に入力欄が出て、Return で確定すると次の入力欄が出る連続入力方式(詳細は screen-design.md「操作方法の整理」)<br>・タスクカードをクリック(スマホはタップ)すると、編集ダイアログが開く<br>・編集ダイアログでタイトル・メモ・期限日を変更できる<br>・編集ダイアログからタスクを削除できる。削除時は確認ダイアログを表示する<br>・分類の変更はドラッグ&ドロップでも可能(PC。スマホは長押しメニュー) | 確定 |
| F-05 | 並び替え | ・同じ分類内でもドラッグ&ドロップで上下の並び順を変更できる(スマホは編集モード)<br>・分類を移動する際の位置は、screen-design.md「操作方法の整理」の配置ルールで決まる(任意の位置は選べない)<br>・並び順はデータベースに保存し、ブラウザを再起動しても維持する<br>・期限日順などの自動並べ替えは今回は不要 | 確定 |
| F-06 | タスクの項目 | タイトル、メモ、期限日(任意)を持つ。分類と期限日は別々に管理し、期限日を変えても分類は自動で変わらない(逆も同様) | 確定 |
| F-07 | 「日常・学習・仕事」の区別 | 種類タグは現時点では追加しない(シンプルな構成で始める) | 確定(今回は見送り) |
| F-08 | 完了タスクの扱い | ・「完了」列に移したタスクは、削除するまで残す<br>・ブラウザを再起動しても保持する<br>・自動削除は行わない<br>・一括削除機能は今回は実装しない(必要になった段階で追加を検討) | 確定 |
| F-09 | 対応端末・画面 | ・PC とスマートフォンの両方に対応する<br>・PC では 4 つの分類を横並びで表示する<br>・スマートフォンでは画面幅に合わせたレスポンシブデザインにする<br>・スマートフォンでは 4 つの分類を縦に積んで表示する<br>・スマートフォンでもタスクの移動ができる。基本操作は長押しによる移動メニュー(screen-design.md「操作方法の整理」参照)<br>・通常のスクロール操作と干渉しないようにする<br>・複雑さを抑え、基本操作が両方の端末で正常に動くことを優先する | 確定 |
| F-10 | ログイン・ログアウト | 1 人専用のパスワード認証。ログアウト時はサーバー側でもログイン状態を無効化する(tech-stack.md「認証・アクセス制御」) | 確定 |
| F-11 | 期限切れ表示 | 期限日を過ぎた未完了タスクの期限日を、赤い文字+警告アイコン「!」で強調する(screen-design.md「操作方法の整理」) | 確定 |
| F-12 | ダークモード | OS・端末の外観設定に合わせて、自動で切り替わる(screen-design.md「表示テーマ」) | 確定 |
| F-13 | 移動後の通知 | 分類を移動したあと、画面下に通知メッセージを数秒間表示する([screen-design.md](screen-design.md) 4.3・5.6) | 確定 |
| F-14 | 読み込み・保存・通信エラーの表示 | 読み込み中、保存失敗、通信エラー、他の端末との食い違い(競合)を、画面に表示する(requirements.md 5 章「保存・通信エラー時の表示」) | 確定 |
